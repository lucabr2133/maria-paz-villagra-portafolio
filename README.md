# María Paz Villagra — Portfolio

Sitio web y portfolio profesional de **María Paz Villagra**, estudiante de Licenciatura en Diseño Gráfico en UCASAL. Especializada en diseño editorial, creación de marcas, branding, diseño de packaging y comunicación visual.

---

## ✨ Características

- ⚡ **Astro 5:** Rendimiento ultra rápido con arquitectura de islas y rutas estáticas.
- 🎨 **Tailwind CSS v4:** Estilos modernos y diseño responsive editorial.
- 🌊 **Animaciones GSAP & ScrollTrigger:** Transiciones suaves, parallax y animaciones pop-up al scrollear.
- 📜 **Smooth Scrolling con Lenis:** Scroll fluido integrado con GSAP tickers.
- 📱 **Diseño 100% Adaptable:** Experiencia óptima tanto en desktop como en dispositivos móviles.
- 🗂️ **Galerías Interactivas:** Presentación de proyectos con vista cinematográfica y tarjetas apiladas con efecto 3D tilt.

---

## 🛠️ Stack Tecnológico

- **Framework:** [Astro](https://astro.build/)
- **Lenguaje:** TypeScript / HTML / CSS
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animaciones:** [GSAP](https://gsap.com/) & ScrollTrigger
- **Scroll Suave:** [Lenis](https://lenis.darkroom.engineering/)
- **Componentes:** [React 19](https://react.dev/)
- **Gestor de paquetes:** [pnpm](https://pnpm.io/)

## 🚀 Instalación y Desarrollo Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/lucabr2133/maria-paz-villagra-portafolio.git
   cd maria-paz-villagra-portafolio
   ```

2. **Instalar dependencias con pnpm:**
   ```bash
   pnpm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   pnpm run dev
   ```
   Abrí [http://localhost:4321](http://localhost:4321) en tu navegador.

4. **Compilar para producción:**
   ```bash
   pnpm run build
   ```

5. **Previsualizar la compilación:**
   ```bash
   pnpm run preview
   ```
